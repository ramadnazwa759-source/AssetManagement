# SISTEM OPERASIONAL ASSET MANAGEMENT Kalisawah Advanture Banyuwangi 

Kelas: 3B TRPL

Deskripsi
Sistem Informasi Manajemen Aset merupakan aplikasi berbasis web yang digunakan untuk membantu proses pengelolaan aset secara lebih terstruktur. Sistem ini mencakup pengelolaan data aset, kategori aset, subkategori, jenis aset, lokasi, kondisi, status, serta proses peminjaman dan pengembalian aset. Aplikasi ini dibuat untuk memudahkan admin dalam melakukan input, pembaruan, dan monitoring data aset sehingga proses manajemen aset dapat dilakukan dengan lebih terorganisir dan efisien.
